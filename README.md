# 📁 FileFlow

### A Smart Desktop File Organizer

FileFlow is a Python-based desktop application that automatically organizes files into categorized folders based on their file extensions.

## ✨ Features

- 📂 Select folders using a graphical interface.
- ⚡ Automatically organize files into categories.
- 🖼️ Categorize Images, Documents, Videos, Audio, Archives and Code.
- 🔒 Prevent overwriting files with duplicate names.
- 💻 Simple and user-friendly desktop interface.
- ✅ Display organization results.

## 🛠️ Technology Stack

| Technology | Purpose              |

| Python     | Backend logic        |
| PyWebView  | Desktop application  |
| HTML       | Interface structure  |
| CSS        | Interface styling    |
| JavaScript | Frontend interaction |
